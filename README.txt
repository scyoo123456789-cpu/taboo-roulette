금기 룰렛 (Taboo Roulette) - Minecraft 26.3 Fabric 모드
==========================================================

5분마다 화면 가운데에서 룰렛이 돌고, 뽑힌 금기 행동은 영구적으로 막힙니다.
금기는 12개라서 60분이 지나면 전부 잠깁니다. 싱글플레이 전용입니다.


[1] 준비물 (처음 한 번만)
----------------------------------------------------------
  1. JDK 25 (Temurin) - 모드 파일을 만드는(빌드) 데 필요합니다.
     https://adoptium.net/temurin/releases/
     -> Windows / x64 / JDK / 25 선택 -> .msi 받아서 설치
     ※ 설치 화면의 "Set JAVA_HOME variable" 항목을 '설치'로 바꿔 주세요.

  2. Fabric Loader (26.3용)
     https://fabricmc.net/use/installer/

  3. Fabric API (26.3용 jar)
     https://modrinth.com/mod/fabric-api


[2] 모드 파일(.jar) 만들기
----------------------------------------------------------
  1. 이 폴더의 build-mod.bat 를 더블클릭합니다.
  2. 처음에는 5~10분 걸립니다. (마인크래프트, 라이브러리 다운로드)
  3. 끝나면 output 폴더가 열리고 taboo-roulette-1.0.0.jar 가 생깁니다.

  ※ 실패하면 검은 창의 오류 메시지를 복사해서 Claude 에게 보여주세요.


[3] 설치
----------------------------------------------------------
  %appdata%\.minecraft\mods 폴더에 아래 두 파일을 넣습니다.
    - taboo-roulette-1.0.0.jar
    - fabric-api-(26.3용).jar
  마인크래프트 런처에서 fabric-loader-26.3 프로필로 실행하세요.


[4] 사용법 (채팅창에 입력 / 치트 허용 안 해도 됨)
----------------------------------------------------------
  /taboo start    타이머 시작 (5분 뒤 첫 룰렛)
  /taboo pause    일시정지
  /taboo resume   이어서 진행
  /taboo spin     지금 바로 룰렛 돌리기 (테스트, 촬영 편집용)
  /taboo status   현재 상태 보기
  /taboo reset    전부 초기화

  ※ 진행 상황은 월드 폴더의 taboo_roulette.json 에 저장되어 껐다 켜도 이어집니다.
  ※ ESC 로 게임을 멈추면 타이머와 룰렛도 함께 멈춥니다.
  ※ 오른쪽 위: 다음 금기까지 남은 시간 + 지금까지 걸린 금기 목록
  ※ 물약 효과가 있으면 효과 아이콘 아래로 내려갑니다.


[5] 금기별로 막히는 것
----------------------------------------------------------
  채굴 금지        블록 캐기 전부. 때리는 모션도 나오지 않습니다.
  공격 금지        모든 근접 공격 (엔드 수정 치기 포함)
  거동 금지        W A S D, 달리기 입력 전부 (보트, 말 조종 포함)
                   넉백이나 물살에 밀려 움직이는 것은 가능
  점프 금지        땅에서 점프 불가. 물속에서 위로 헤엄치는 것은 가능
  방패 금지        방패를 들 수 없음 (들고 있던 중이면 즉시 내려감)
  웅크리기 금지    Shift 입력 무시 (웅크리기 '전환' 모드도 포함)
  음식 금지        음식, 케이크 먹기 불가. 우유와 물약 마시기는 가능
  블록간 상호작용 금지
                   상자, 문, 작업대, 화로, 침대, 버튼, 레버 등 블록 우클릭 기능 전부
                   (손에 든 블록을 설치하는 것은 설치 금지 전까지 가능)
  부활 금지        죽으면 리스폰 후 관전 모드로 전환, 챌린지 실패 처리
                   불사의 토템은 리스폰이 아니므로 그대로 작동
  피 회복 금지     자연회복, 재생, 치유 물약, 황금사과 회복 전부
                   (황금사과의 흡수 하트는 생깁니다)
  설치 금지        모든 블록, 물/용암 양동이, 보트, 수레, 갑옷 거치대, 그림,
                   액자, 엔드 수정, 불 붙이기, 엔드 차원문에 엔더의 눈 끼우기
  투사체 금지      활, 쇠뇌, 삼지창, 눈덩이, 달걀, 엔더 진주, 엔더의 눈 던지기,
                   투척/잔류 물약, 경험치 병, 낚싯대, 돌풍구, 폭죽
